# Kit de piezas fotográficas (recortes)
Generadas el 2026-11-23 con la API de imágenes de Gemini (gemini-2.5-flash-image), con la cuenta del propio proyecto.
Personas y objetos FICTICIOS y genéricos (cuerpos sin cabeza, guantes, accesorios): no representan a ninguna persona real.
Recortadas con `lienzo/recorte.js` (fondo croma liso → PNG con alfa) y reducidas a 900 px. Generadas sobre fondo verde (#00FF00)
o magenta (#FF00FF) según el color de la prenda. Se descartaron las manos desnudas: salían con la muñeca "cortada".
Para ampliar el kit: scripts de generación en el historial de git (scripts/_img.js) y `node scripts/recortar-kit.js`.
