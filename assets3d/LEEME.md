# assets3d
Assets 3D descargados con permiso del usuario (2026-11-24). No se versionan (ver .gitignore); `MANIFEST.json` sí: fuente, licencia leída en la página oficial, fecha y huella de cada archivo.
Catálogo y criterios: `docs/biblioteca-3d/`. Registrar un archivo nuevo: `node scripts/assets3d-registrar.js <archivo> --fuente <url> --licencia "<texto>"`.
